# 0005. Element Plus 版本基线演进与双轨兼容策略

## 状态

Accepted (已接受)

## 背景与决策上下文

Element Plus 已发布最新的生产正式版本 **`2.14.7`**（发布于 2026 年 9 月 30 日），同时 Vue 3.5 已稳定迭代至 **`3.5.44`**。

从 2.8.0（2024 年 8 月）演进至 2.14.7（2026 年 9 月），Element Plus 经历了两年的持续维护：

1. **深度适配 Vue 3.5 响应式体系**：进一步优化了内部虚拟列表、表格多级表头与动态行高计算；
2. **TypeScript 5.5+ 类型推断强化**：表单校验规则 `FormRules` 与表格实例类型导出更加严密；
3. **API 契约向后兼容**：严格遵循 SemVer 2.x 规范，核心组件（`ElTable`、`ElButton`、`ElDialog` 等）的对外 Props、Slots 与 Emits 契约保持向后兼容。

在企业级中后台基础设施建设中，我们需要平衡两组矛盾的诉求：

- **诉求一（公共库兼容度）**：外部企业消费方可能停留在 2.8.x 或 2.9.x，若底层库强制锁定 `^2.14.0`，会导致依赖安装时出现 peerDependencies 冲突警告；
- **诉求二（自验沙箱最新性）**：我们的 1:1 体验展厅（`sample-element-plus`）必须对标当前官方最新的成熟度基准，验证在最新版本下的表现。

## 架构决策

1. **基础设施库宽泛包容**：`@atengk/element-plus` 的 `peerDependencies` 统一声明为 **`"element-plus": ">=2.8.0"`** 与 **`"vue": ">=3.5.0"`**，双向包容存量项目与新项目，消灭 peer 冲突告警；
2. **自验展厅与 CI 环境最新守护**：`apps/sample-element-plus` 将依赖显式锁定为最新的 **`"element-plus": "^2.14.7"`** 与 **`"vue": "^3.5.44"`**，确保所有新封装组件（如 `AtengTable`、`AtengExcelFeedback`）100% 在当前最新的官方稳定产物下通过回归自验；
3. **生态推荐指引**：在文档与快速开始指南中明确推荐下游项目配套使用 `element-plus: ^2.14.0+`，以获得最佳的暗黑模式 CSS 变量与无障碍访问（A11y）支持。

## 效果与权衡

- **收益**：最大化消除外部项目的接入阻力，同时保证本工程自验与构建始终处于最先进、最稳定的生产状态。
- **代价**：在编写底层库代码时，必须避免使用仅在 2.14 内部新增、而在 2.8 中缺失的私有实验性 API，始终面向标准的公共组件契约编程。

# 0011. L0 核心底座高可用韧性、流式通信与数据安全增强架构

## 状态

Accepted (已接受)

## 背景与决策上下文

随着 `@atengk/core` (L0) 纯原生核心底座的建立，系统在统一响应契约、Axios 强类型管道、64位雪花 ID 防截断、通用 Token 凭据与安全下载方面已具备扎实基线。然而，面向现代企业级中后台、AI 协同系统与复杂微服务架构，前端基础设施面临八项深水区挑战：

1. **AI 大模型流式输出 (SSE)**：传统 Axios 在浏览器端处理 `text/event-stream` 与 `ReadableStream` 增量解析极为笨重，无法直接满足大模型推理打字机流式交互；
2. **网络偶发抖动与故障扩散**：弱网或微服务网关瞬态波动易导致前端直接报错，但无脑重试会引发写操作重复扣款等严重脏写事故；
3. **并发调用网络雪崩**：组件树深层挂载时并发请求同一只读元数据（如数据字典），导致短时间内向网关发起重复冗余请求；
4. **前端浮点数金额失真**：JavaScript `Number` 浮点数运算存在经典失真问题（`0.1 + 0.2`），且“分”与“元”转换时的舍入截断易酿成资金故障；
5. **多租户全链路隔离**：微服务 SaaS 架构强制要求在请求头上透传租户标识；
6. **本地缓存无限堆积**：裸用 `localStorage` 缺乏生命周期（TTL）与命名空间管理，久置产生大量脏数据；
7. **大文件切片上传空白**：缺乏大文件切片、受控并发上传、断点续传与进度调度门面；
8. **安全防重放与签名合规**：金融/政企等保要求核心写接口必须携带时间戳、Nonce 随机数与签名摘要。

## 架构决策

为在恪守“**纯 TypeScript、平台与框架中立、零 UI 依赖、原生优先与零臃肿依赖**”的前提下解决上述挑战，确立以下八项增强架构：

1. **Web 原生流式响应门面 (`StreamClient`)**：
   - 基于浏览器与 Node 原生 `fetch` 及 `ReadableStream` 封装流式客户端，支持逐块解析 SSE 消息流与打字机效果；
   - 自动集成 `AuthManager` 鉴权头注入与 `AbortSignal` 级联中断。
2. **幂等安全重试状态机 (`RetryPolicy`)**：
   - 在 `HttpClient` 请求管道中内置受控重试机制，支持可配置的指数退避（Exponential Backoff）；
   - **刚性安全防线**：默认且强制仅对 GET、HEAD 等幂等只读请求以及网络断连/5xx 错误生效；对 POST/PUT/DELETE 等非幂等写操作严格禁自动重试，杜绝资金重复扣款。
3. **飞行中并发请求去重合并 (`RequestDeduplicator`)**：
   - 针对同时触发的相同指纹（Method + URL + Params）只读请求，复用同一个正在执行中的 pending Promise，使向后端的瞬态请求数由 N 降为 1。
4. **金融级纯原生金额精度计算与格式化 (`Currency`)**：
   - 坚持纯原生无第三方重型数学库依赖，基于整数位移与字符串精确补齐实现 `toCents`（元转分）、`toYuan`（分转元）与 `formatCurrency`（标准千分位）。
5. **多租户上下文门面 (`TenantManager`)**：
   - 对标 `AuthManager` 规范，提供租户 ID 的持久化、读取与请求头（`X-Tenant-Id`）自动注入。
6. **带 TTL 时效与命名空间缓存 (`CacheStorage`)**：
   - 封装支持存活时长（TTL）、命名空间前缀隔离与过期自动垃圾清理的本地键值缓存。
7. **大文件切片与并发上传协调器 (`UploadCoordinator`)**：
   - 提供原生 `createFileChunks` 切片纯函数与受控并发上传调度器，支持最大并发度限制、切片进度统计、单片重试与中断取消。
8. **防重放与原生签名机制 (`RequestSigner`)**：
   - 基于原生 Web Crypto API (`crypto.subtle.digest`) 计算 SHA-256 签名，支持时间戳校验与 Nonce 防重放。
9. **业务强类型断言与类型收窄工具箱 (`Assertions`)**：
   - 提供 `assert` 与 `assertNonNull` 卫语句，不满足时统一抛出 `BusinessException`，并在编译期实现 TypeScript 类型安全收窄。

## 效果与权衡

- **收益**：
  - `@atengk/core` 形成全功能、高韧性、工业级的纯原生基础设施底座，为上层 Vue/React 响应式层与组件库提供坚若磐石的数据与网络支撑；
  - 坚持纯原生实现，产物增量极小，零臃肿第三方依赖。
- **代价**：
  - 底座需维护更丰富的单元测试与边界用例；
  - 开发者需遵循“写操作不重试、流式优先 StreamClient”的设计规范。

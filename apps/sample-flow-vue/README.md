# sample-flow-vue 企业级流程与审批流转自验展厅

> 专注于演示与自验 `@atengk/flow-vue` 核心特性（流程编排设计器、只读流转追踪器、五态高亮与流动虚线、悬停审批审计浮层、三段式物料面板、属性配置抽屉插槽反转、四向磁吸正交折线防呆、DAG 自动分层排版、静态拓扑图论校验、BPMN 2.0 XML 双向转译、2x/3x DPR 全景防虚快照与防泄密文本矩阵水印、Vue 3 SFC 卡片节点注册以及低代码规则引擎 DAG）在真实业务场景下的开箱使用与交互自验。

---

## 1. 快速启动与服务端口

- **默认固定端口**：`3007` (严格遵守 ADR-0001 / ADR-0009 / CONTEXT-MAP 端口契约)
- **启动方式**：
  ```bash
  pnpm --filter sample-flow-vue dev
  ```
- 启动后浏览器访问：`http://localhost:3007`

---

## 2. 运行环境与 Mock 双模切换

- **默认/CI 模式**：内置 100% 离线自洽的流程拓扑数据模型（企业费用报销审批流、采购合同会签流、ITSM 运维工单流转流、ETL 规则链管道），无需启动或依赖任何外部物理后端与工作流引擎服务，即可体验全部核心功能与跑通自动化测试；
- **Local 真实网关模式**：若需直连真实微服务网关或后端 Flowable / Camunda 流程引擎服务，在工程根目录创建 `.env.local` 并配置 `VITE_API_BASE_URL`，开发服务自动代理直连真实工作流接口（该环境配置文件已被 Git 严格忽略，CI 零风险）。

---

| **属性抽屉与表单插槽**      | `src/scenarios/PropertyPanelSlotScenario.vue` | 点击选中节点或连线，切换“原生轻量模式”与“Element Plus 插槽接管模式”，修改审批人、会签模式与条件表达式         | 验证通用元数据双向回写、L2 零 UI 依赖与 `#panel` 具名插槽 100% 控制反转能力                                        |
| **运行态工单流转追踪**      | `src/scenarios/ViewerAuditScenario.vue`       | 点击切换流转阶段（部门审批中 ➔ 总监审批中 ➔ 模拟驳回 ➔ 全景办结），鼠标悬停节点查看审批履历卡片，点击待办定位 | 验证只读流转呈现、五态高亮与流动虚线、悬停审批审计浮层（`#audit-popover` 插槽）、SmartFocus 待办聚焦与滚轮防冲突   |

### 💡 高频特色交互与自验热键速查卡

在展厅自验过程中，可通过以下键盘与鼠标微交互秒级体验设计器与追踪器的工业级特性：

| 特色交互场景            | 触发方式与操作口诀                                                 | 预期交互反馈                                                                          |
| :---------------------- | :----------------------------------------------------------------- | :------------------------------------------------------------------------------------ |
| **键盘快捷键操作**      | 选中节点后按 `Delete` 删除；按 `Ctrl + Z` 撤销，按 `Ctrl + Y` 重做 | 节点平滑移除或恢复，历史操作栈完整回退；多选图元按 `Ctrl + C` / `Ctrl + V` 原地克隆   |
| **拓扑连线防呆守卫**    | 拖动连线连向节点自身，或从终点节点反向连出                         | 触发 `beforeConnect` 拦截守卫，连线自动弹回，状态栏即时提示拓扑违规原因               |
| **图论异常脉冲高亮**    | 在校验排版看板选择“异常注入”并点击“执行静态校验”                   | 涉事节点边框即刻呈现红色发光脉冲呼吸动画（`at-flow-pulse-error`），右侧滑出诊断报告   |
| **页面滚轮防冲突**      | 在运行态追踪看板中直接滚动鼠标滚轮                                 | 仅外层主页面滚动，画布视口不误缩放；必须**按住 `Ctrl` 键配合滚轮**才触发画布缩放      |
| **SmartFocus 待办定位** | 在运行态看板点击“🎯 SmartFocus 待办定位”按钮                       | 画布视口平滑平移居中至当前处理中（Processing）或待办（Pending）节点，消除大图盲目寻迹 |
| **表单插槽 100% 反转**  | 在属性抽屉看板点击切换“抽屉表单形态”                               | 属性抽屉在极简原生无依赖表单与 Element Plus `<el-form>` 高阶表单间即时无缝切换        |

## 4. 全真自动化回归命令

在自验展厅与核心子包交付前，必须在本地依次执行并通过以下四道全真质量门禁：

```bash
pnpm --filter @atengk/flow-vue --filter sample-flow-vue typecheck && \
pnpm --filter @atengk/flow-vue --filter sample-flow-vue lint && \
pnpm --filter @atengk/flow-vue test && \
pnpm --filter sample-flow-vue build
```

> 详细原理机制、Props/Options 强类型契约清单与生产防御边界，请参阅核心子包权威真理源文档：[@atengk/flow-vue README](../../packages/flow-vue/README.md)。

# sample-gantt-vue 高性能甘特图与资源排程自验展厅

> 专注于演示与自验 `@atengk/gantt-vue` 核心特性（基于 VisActor 高性能 Canvas 引擎的甘特图排程、双栏像素级同步滚动、多级 WBS 树形折叠、双模数据自适应、自底向上工期/进度 Rollup 汇总推算、前后置依赖 FS/SS/FF/SF 拓扑判环防呆、计划基准线对比与工期延误智能预警、5 大时间刻度平滑无缝缩放、原生脱壳模态弹窗 `<AtengGanttModal />`、Design Tokens 驱动与暗黑模式无损热跟随、Retina 高清防虚全景图片导出）在真实业务场景下的开箱使用与交互自验。

---

## 1. 快速启动与服务端口

- **默认固定端口**：`3018`（严格对齐 ADR-0001 / ADR-0009 / CONTEXT-MAP 端口契约）
- **启动方式**：
  ```bash
  pnpm --filter sample-gantt-vue dev
  ```
- 启动后浏览器访问：`http://localhost:3018`

---

## 2. 运行环境与 Mock 双模切换

- **默认/CI 模式**：内置 100% 离线自洽的研发项目与工程管廊真实业务模拟数据集（`src/data/mock-gantt-data.ts`），无需启动或依赖任何外部物理后端与数据库，即可体验完整排程交互与跑通自动化测试；
- **Local 真实网关模式**：若需直连真实后端微服务排程接口，在工程根目录复制 `.env.example` 为 `.env.local` 并配置 `VITE_API_BASE_URL`，重启开发服务即可代理直连真实接口（该环境配置文件已被 Git 严格忽略，CI 零风险）。

## 4. 全真自动化回归命令

在自验展厅与核心子包交付前，必须在本地依次执行并通过以下四道全真质量门禁：

```bash
pnpm --filter @atengk/gantt-vue --filter sample-gantt-vue typecheck && \
pnpm --filter @atengk/gantt-vue --filter sample-gantt-vue lint && \
pnpm --filter @atengk/gantt-vue test && \
pnpm --filter sample-gantt-vue build
```

> 详细原理机制、Props/Options 强类型契约清单与生产防御边界，请参阅核心子包权威真理源文档：[@atengk/gantt-vue README](../../packages/gantt-vue/README.md)。

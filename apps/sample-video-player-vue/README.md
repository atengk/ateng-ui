# sample-video-player-vue

`@atengk/video-player-vue` 1:1 独立镜像自验展厅与全真交互沙箱。

基于 Vite 6 + Vue 3.5 构建，完全遵循 L2 专用能力扩展层中立规范（零 Element Plus 依赖），用于在真实浏览器环境下端到端验证音视频点播、低延迟直播、监控矩阵、安防云台控制、防录屏安全水印与高性能弹幕系统。

---

## 包含的交互演示模块 (8 大专区)

1. **标准富媒体点播 (VOD)**：
   - 验证标准 MP4/WebM 点播、清晰度画质无缝切换、倍速档位选择、视频截图导出与命令式 API（播放/暂停/跳帧/音量控制）联动。
2. **点播深水区 (Deep VOD)**：
   - 验证全局键盘快捷键（空格、方向键、F全屏、M静音、[,]/[,]逐帧步进）；
   - 验证时间轴事件打点高亮与悬浮卡片提示，点击打点精准跳转；
   - 验证进度条 Hover 雪碧图切片/WebVTT 动态帧卡片预览；
   - 验证本地播放历史记忆续播（自动读取、弹窗提示、一键重新播放）。
3. **企业鉴权与防线 (ADR-0004)**：
   - 验证 `TokenInjector` 凭据双轨自动注入（`token` 与 `Authorization: Bearer`）；
   - 验证 `BlobJsonGuard` 双态异常识别（拦截 401/403/500 JSON 报错并转译为业务异常抛出，防白屏死锁）；
   - 验证确定性销毁六步防线与 GPU 缓冲释放。
4. **流媒体低延迟直播 (HLS/FLV)**：
   - 验证 HLS (`.m3u8`) 直播流解封装与 Safari 原生降级；
   - 验证 HTTP-FLV 低延迟直播拉流、毫秒级追帧算法与 `SourceBuffer` 内存防爆；
   - 验证断流自动指数退避重连状态机（最大重试、抖动抗惊群、倒计时与手动重试）。
5. **多路分屏协同矩阵 (1~16 屏)**：
   - 验证 `1x1`、`2x2`、`3x3`、`4x4` 对称宫格及 `1+5`、`1+7` 广播级主从分屏；
   - 验证选路聚焦（高亮边框）、双击单路独占放大与按 ESC / 双击平滑恢复宫格；
   - 验证主次码流自适应不变量（非独占展示低码率 `subUrl` 节约 70% 带宽，独占放大秒切高清 `url`）；
   - 验证多路音频互斥不变量（仅聚焦路发声，背景路强制静音）；
   - 验证自动巡更轮巡调度器（定时平滑翻页）。
6. **安防云台控制 (PTZ)**：
   - 验证八方向云台调控罗盘与停止按键（支持长按、松开自动 stop）；
   - 验证变焦 (Zoom)、聚焦 (Focus)、光圈 (Iris) 按键与速度档位滑块；
   - 验证预置位快捷调用、保存当前点位与删除；
   - 验证纯前端 CSS Transform 硬件加速电子放大 `useDigitalZoom`（1.0x~5.0x 滚轮无级缩放与平移漫游，边界阻尼防脱框）；
   - 验证画面手势联动 `usePtzGesture`（拖拽矢量精准映射 8 方向扇区指令，滚轮变倍）。
7. **防录屏安全水印 (DLP)**：
   - 验证 Canvas/SVG 矢量平铺水印与样式配置（内容、字号、颜色、倾角）；
   - 验证动态微位移随机浮动（破坏录屏软件插帧反算法）；
   - 验证 F12 攻防审查防篡改（MutationObserver 毫秒自愈重建与 `@watermark-tampered` 安全告警）；
   - 验证容器级全屏穿越（全屏状态下水印稳定覆盖不脱落）。
8. **弹幕系统与多字幕 (Danmaku & Subtitles)**：
   - 验证独立按需分包 `@atengk/video-player-vue/plugins/danmaku` 插件注入（Tree-Shaking 0 字节残留）；
   - 验证 Canvas 弹幕通道池防碰撞与防追尾排布调度；
   - 验证实时弹幕发射（支持滚动、顶部、底部模式与自发高亮外框）；
   - 验证弹幕透明度、速度、屏占比调节与屏蔽规则（屏蔽顶部/底部/彩色/关键词）；
   - 验证 WebVTT 与 SRT 规范多轨双语字幕动态切换与字号样式微调。

pnpm --filter sample-video-player-vue build

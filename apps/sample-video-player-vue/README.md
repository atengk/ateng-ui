## 1. 快速启动与服务端口

- **默认固定端口**：`3005` (严格遵守 ADR-0001 / ADR-0009 / CONTEXT-MAP 端口契约)
- **启动方式**：
  ```bash
  pnpm --filter sample-video-player-vue dev
  ```
- 启动后浏览器访问：`http://localhost:3005`

---

## 2. 运行环境与 Mock 双模切换

- **默认/CI 模式**：内置公开合规的高清音视频测试流（如 Artplayer MP4、Mux HLS 直播切片、Akamai 演示源）与自洽 Mock 故障注入源（模拟 401/403 鉴权失败、断流信号丢失），无需启动任何外部后端服务即可在浏览器中体验完整交互与跑通自动化测试；
- **Local 真实网关/摄像头模式**：若需对接企业安防流媒体网关（如 GB28181、ZLMediaKit、WVP-PRO）或局域网 RTSP 转 HLS/FLV 真实摄像头，可直接在各 Demo 界面的输入框中粘贴流直链，或在工程根目录创建 `.env.local` 并配置 `VITE_STREAM_BASE_URL`，开发服务自动代理直连真实流媒体服务（该环境配置文件已被 Git 严格忽略，CI 零风险）。

## 4. 全真自动化回归命令

在自验展厅与核心子包交付前，必须在本地依次执行并通过以下四道全真质量门禁：

```bash
pnpm --filter @atengk/video-player-vue --filter sample-video-player-vue typecheck && \
pnpm --filter @atengk/video-player-vue --filter sample-video-player-vue lint && \
pnpm --filter @atengk/video-player-vue test && \
pnpm --filter sample-video-player-vue build
```

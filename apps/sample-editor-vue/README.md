# sample-editor-vue 现代富文本与内容创作自验展厅

> 专注于演示与自验 `@atengk/editor-vue` 核心四大场景预设（Simple, Notion-like, DOCX, Agent）、表格人体工学、选区气泡、块级斜杠命令、媒体资产直传拦截、字数硬限制与纯前端 OpenXML 导出在真实业务场景下的开箱使用与交互自验。

---

## 1. 快速启动与服务端口

- **默认固定端口**：`3009` (严格遵守 ADR-0001 / ADR-0009 / CONTEXT-MAP 端口契约)
- **启动方式**：
  ```bash
  pnpm --filter sample-editor-vue dev
  ```
- 启动后浏览器访问：`http://localhost:3009`

---

## 2. 运行环境与 Mock 双模切换

- **默认/CI 模式**：内置 100% 离线自洽 Mock 逻辑（涵盖 `createMockAiStreamHandler` 离线打字机仿真器、30ms/字渐进式吐字、Base64 媒体资产优雅降级与静态场景预设），无需启动或依赖任何外部物理网络与真实后端大模型服务即可跑通完整交互与自动化检查；
- **Local 真实网关模式**：若需直连真实大模型 SSE 网关或业务私有 OSS 资产上传接口，复制 `.env.example` 为 `.env.local` 并配置 `VITE_API_BASE_URL`，重启开发服务即可直连真实接口（该环境配置文件已被 Git 严格忽略，CI 零风险）。

## 4. 全真自动化回归命令

在自验展厅与核心子包交付前，必须在本地依次执行并通过以下四道全真质量门禁：

```bash
pnpm --filter @atengk/editor-vue --filter sample-editor-vue typecheck && \
pnpm --filter @atengk/editor-vue --filter sample-editor-vue lint && \
pnpm --filter @atengk/editor-vue test && \
pnpm --filter sample-editor-vue build
```

> 详细原理机制、Props/Options 强类型契约清单与生产防御边界，请参阅核心子包权威真理源文档：[@atengk/editor-vue README](../../packages/editor-vue/README.md)。
